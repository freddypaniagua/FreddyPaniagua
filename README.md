# Freddy Paniagua

Personal site for an aspiring software engineer studying computer science and linguistics at UCLA.

**Live:** [freddypaniagua.github.io/FreddyPaniagua](https://freddypaniagua.github.io/FreddyPaniagua/)

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Pages: Home, Projects, About, Resume, and Contact.

## Deploy

Pushes to `main` publish the site on GitHub Pages.
