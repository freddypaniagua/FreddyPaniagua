## What I'm building

**[Tipping Point](https://freddypaniagua.github.io/tipping-point-game/)** · TypeScript, Vite, GitHub Pages<br>
An estimation game that runs in the browser: guess how many of one object it takes to balance another on a scale, like blue whales against the Eiffel Tower. After you commit to a guess, an animated scale stacks up your objects and tips toward the heavier side, and your score is based on how many times too high or too low you were, so huge and tiny answers are judged fairly. It's designed as a daily game where every player gets the same 5 puzzles. *In development: one puzzle set is playable now.*

**CSCAN** · C++17, Qt6, Tesseract OCR<br>
A real-time economy advisor for Counter-Strike 2. It captures the screen with Qt, uses Tesseract OCR to read your money, side, and score off the game's display, and runs that through a C++ decision engine that recommends what to buy each round: full buy, force buy, eco, or save. It works only from what's on screen and never reads or changes the game's memory. *In progress: making screen reading work reliably at every resolution.*

**Drop Tones** · JavaScript, Web Audio API, Node.js<br>
A browser-based DJ battle game where two players mix music live and compete head-to-head, or one player takes on a bot. Sounds are generated in code with the Web Audio API and kept in sync on a shared beat, key, and chord progression, so any combination sounds good together. I'm testing two ways to control the mix: dropping sounds onto characters that each play one part of the song, or a DJ mixer modeled on the real equipment DJs use. *Early development.*
